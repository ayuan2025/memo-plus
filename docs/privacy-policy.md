# 隐私政策

**生效日期：2026-10-07 · 适用版本：memo+ 1.0.x**

memo+ 是本地优先的笔记应用。我们（memo+ 开发者）不收集、不上传、不出售你的任何个人数据。核心原则一句话：**你的数据只在你自己的设备和你自己配置的服务之间流动。**

## 1. 数据存储

- 笔记、图片、扫描件、录音等全部数据默认只保存在你的设备本地。
- 仅当你主动配置并启用以下功能时，数据才会流向你指定的服务：
  - **Memos 同步**：笔记同步到你自建的 Memos 服务器；
  - **WebDAV 备份**：加密备份上传到你指定的 WebDAV 网盘；
  - **局域网迁移**：两台设备之间经局域网直传（不经任何中转服务器）。

## 2. 联网行为

应用只在以下情形访问网络：

| 行为 | 目的地 | 内容 |
| --- | --- | --- |
| 检查更新 | 本项目 GitHub Releases | 仅下载版本号与更新说明（latest.json），不含任何个人数据 |
| Memos / WebDAV 同步 | 你自行配置的服务器 | 你的笔记数据，全程不经过开发者 |
| 逆地理编码（可选） | 你选择的高德 / 百度 / Google 服务 | 仅当你给笔记附加位置时，发送当前坐标 |
| AI 功能（可选） | 你自行配置的 AI 服务商 | 仅当你主动使用 AI 摘要等功能时，发送你指定的笔记内容 |

应用**没有**统计 SDK、广告 SDK、崩溃上报或任何遥测。

## 3. 权限使用

- **相机 / 相册**：拍摄、导入、扫描文档，导出卡片图片；
- **麦克风**：录制语音笔记；
- **位置（可选）**：仅在你选择给笔记附加位置时使用；
- **本地网络**：局域网设备迁移发现。

## 4. 日志

应用产生的诊断日志仅保存在设备本地，只有你手动导出分享时才会离开设备。

## 5. 开源组件

本应用基于多个开源项目构建，见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。其中扫描引擎与文字识别均在设备端离线运行。

## 6. 联系方式

对本政策有任何疑问，请到 GitHub 仓库提交 Issue。

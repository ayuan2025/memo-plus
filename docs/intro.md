笔记App 最大的坑是**存得进、搜不到**。尤其是纸质资料——证件、合同、发票、说明书，拍完存进相册就等于存进了黑洞。

memo+ 缝了三个开源项目进来，解决三个痛点：

| 痛点 | 缝进来的能力 |
| --- | --- |
| **图片里的文字搜不到** | ML Kit **离线 OCR**，识别结果直接进全文索引 |
| **证件档案存进去就乱** | 文档扫描识别引擎 + **15 类证件/单据自动分类** |
| **笔记不好看、分享很丑** | 锤子便签风格**卡片主题**，编辑/阅读页内可直接预览 |

**前两点都是围绕「怎么搜回来」，第三点解决「怎么好看地分享出去」。**

---

## 一、图片里的文字搜不到 → 离线 OCR 全文检索

纸质文件、证件、发票拍成图片后，普通笔记 App 无法检索里面的文字——你记得存过，却想不起那句内容写了什么。

memo+ 内置 **ML Kit 离线文字识别**：扫描件在本地完成 OCR，**识别结果直接进全文索引**，之后搜关键词就能搜到图片里的文字。

> 这是印象笔记的**付费功能**。这里免费、且**全程离线**——图片不上传任何服务器。

### 完整链路：扫描 → 校正 → 识别 → 归类 → 检索

拍照或导入一张图片，memo+ 会走完一条完整的链路，**全程离线，图片不上传任何服务器**：

1. **扫描引擎**：自动检测纸张边界、透视校正、扫描仪风格色彩滤镜，把一张歪斜、带阴影的随手拍变成平整清晰的扫描件。支持满页智能判定、批量重扫与页内旋转。
2. **离线文字识别（OCR）**：把图里的字变成可检索的文本——**没有网络也能用，也不把你的图片发出去**。
3. **自动分类**：这是 memo+ 与「只是个扫描仪」最大的区别。识别完文字后，它会按文档的**结构**而非文件名自动判断这是什么，并打上归类标签。目前内置 15 类常见单据与证件：

   | 类别 | 识别依据（举例） |
   | --- | --- |
   | 身份证 | 18 位号码 + GB 11643 校验和、姓名/性别/民族等字段 |
   | 护照 | 机读区（MRZ）或护照字样 |
   | 营业执照 | 统一社会信用代码（含禁用字母校验）、法定代表人等 |
   | 发票 / 收据 / 小票 | 发票专用章、价税合计、收银台、谢谢惠顾等 |
   | 驾照 / 行驶证 / 社保卡 / 居住证 / 通行证 | 各自的固定票面字样与字段组合 |
   | 银行卡 / 登机牌 / 车票 / 名片 | 银联、航班号、车次、联系方式组合等 |

   识别是**保守且可证伪**的：身份证必须过校验和、营业执照必须有信用代码里那几个字母、护照优先认机读区——避免把一串普通数字误判成证件。识别出的持有人/单位名称也会被一并提取，方便在列表里一眼认出。

4. **全文搜索**：因为扫描文字已经被提取，你可以用任何关键词（金额、姓名、单位、日期……）**直接在搜索里命中扫描件内容**，而不是只能按文件名找。

> 在「扫完之后怎么和文档相处」这件事上，memo+ 借鉴了同类作品 **「妥帖 (Sorted)」** 的思路——它本身是一款「随手一拍，纸质文件就收好了」的证件 / 单据收纳工具，核心正是扫完即**自动认出这是什么、自动归进对应的类别、一搜就出来**。memo+ 把同样的理念带进了笔记场景：自动归类与全文检索不是扫描的附属功能，而是整条扫描链路的终点——一份凭证扫完即归档，用时一搜即得。
>
> 妥帖 (Sorted) 项目地址：<https://github.com/ayuan2025/sorted-app>

## 二、笔记不好看、分享很丑 → 锤子便签模板

纯文本笔记截图分享出去很丑。memo+ 把一条笔记渲染成**可分享的纸面卡片**，这套卡片的视觉语言取自开源的锤子便签复刻项目 [zhaoolee/notes](https://github.com/zhaoolee/notes)（Apache-2.0）。

- **垂直便签版式**：卡片采用竖版便签样式，文字疏朗、留白克制，导出后发朋友圈、发群里都体面，不再是一坨灰扑扑的纯文本截图。
- **多套模板 / 主题**：内置暖白纸感、深夜便签、备忘录深浅色等多套主题，亮暗随你；同一篇笔记换张「纸」就是另一种气质。
- **编辑/阅读页内可直接「美化预览」**：不必等到导出才知道长什么样——**模板不是只有导出图片时才有用**，写笔记时就能实时预览成稿外观并随手换主题。
- **所见即所得**：应用里看到的排版，就是导出图片里的排版，不会出现「预览挺好、导出走样」。

这一条直接改善了产品的**第一眼观感**——笔记不只是存得住，还存得好看、发得出去。

## 三、本地优先，隐私不打折扣

- **无账号、无遥测**：数据完全存放在本机。
- **可选同步 / 备份**：需要多设备时，可同步到**自建 Memos 服务器**，或用 **WebDAV 加密备份**，钥匙在你自己手里。
- 扫描、OCR 全部离线，图片不外传。

## 四、桌面端

Windows / macOS 桌面形态，支持快捷输入、系统托盘、多窗口，手机上记的，回到电脑上接着写。
